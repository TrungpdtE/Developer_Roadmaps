# Azure CosmosDB

> Nhóm: Databases  
> Mức ưu tiên: Personal must know

## Học để làm gì?

Cloud database multi-model của Azure, nổi bật ở phân tán toàn cầu và consistency levels.

## Kiến thức cốt lõi

- Cloud database giảm vận hành nhưng tăng nhu cầu hiểu billing, region và limits.
- Đọc kỹ consistency model và pricing theo request/storage/throughput.
- Thiết kế partition key sai có thể làm hệ thống nóng một partition.

## Facts cần nhớ

- Mức ưu tiên trong roadmap: **Personal must know**. Bắt buộc học nếu bạn muốn đi Java backend nghiêm túc.
- Nhóm học: **Databases**.
- Học bằng cách tự gõ lại ví dụ, tự đổi bài toán, rồi ghi chú lỗi gặp phải.
- Khi dùng trong production, luôn kiểm tra version, tài liệu chính thức, security advisory và compatibility với JDK/framework hiện tại.

## Ví dụ code hoặc cấu hình

```text
Cloud database checklist:
- Region chính và disaster recovery region là gì?
- Backup giữ bao lâu?
- Throughput tính theo request, capacity unit hay instance?
- Có cần private networking không?
- Dữ liệu nhạy cảm có encryption và access policy chưa?
```
